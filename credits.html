How the licenses were checked

  • Page license box: the hosting SCP Wiki page has a license box entry for that exact file, giving the author and license.
  • Wikimedia Commons metadata: the author and license come from the Commons file page.
  • License on source page: the off-wiki page that hosts the file (for example DeviantArt) marks that specific work with a Creative Commons license.
  • Artist's own page: the artist uploaded the file to their own SCP Wiki gallery page, which is CC BY-SA 3.0. The author is known, but there is no per-file license-box entry.
  • Pending: the image is hosted on, or linked from, a CC BY-SA 3.0 page, but no per-file author or license statement was found. These are not treated as cleared and must be confirmed or replaced before publishing.
  • Withheld: when no license could be found for an entity's own logo or insignia, it is not published. Two group logos (SAPHIR Centre, Wilson's Wildlife Solutions) show a "Logo withheld" plate. The Nu-3 insignia and 61 logos from the Comprehensive List's supplement are replaced by the shared Foundation emblem, marked as a placeholder.

Each image was only resized and converted to WebP. Under CC BY-SA, the adapted copies here are shared under the same license. "Popular" means a widely shared, credited community image for that entry. No view counts or popularity statistics are claimed.

The SCP-173 card does not use the Izumi Kato sculpture photograph, which is not covered by the SCP Wiki's license. It uses a CC BY-SA 3.0 game render from SCP – Containment Breach instead.

The original generated artwork (the SVG plates and the six-second overview films) is still the archive's own work. It appears only under the Original artwork tab inside each anomaly dossier. It is never presented as a downloaded image.
