Original production

All 72 SVG scenes (plus 36 motion-free variants) were drawn specifically for this archive using original geometric artwork. They are symbolic illustrations, not containment photographs or optical images of the entities. No wiki images, official logos, game sounds, or third-party visual assets were used. The R monogram is an original graphic.

The incident vignettes are original fan scenes rather than copied logs or a canonical chronology. All dates are deliberately redacted. Object class describes containment difficulty, not lethality. Every required entry retains its best-known class assignment.

Industrial hum, paper/static rustles, and stamp impacts are synthesized locally using Web Audio. Audio is restrained, starts only after entry, and can always be muted. No account, analytics, or data collection is present. The only saved preference is mute, stored on this device.
